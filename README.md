# LIQUIDWAVE — Windows & Linux releases (beta)

Builds of **LIQUIDWAVE for Windows and Linux**, the music visualizer from [liquidwave.app](https://liquidwave.app). This repository holds release assets only — the app's source is not here.

- **Beta page:** https://liquidwave.app/beta — downloads, install notes and the beta code
- **Windows:** `LIQUIDWAVE-win-Setup.exe` — installs for the current user, no admin rights. The beta installer is not code-signed yet, so SmartScreen asks first: **More info → Run anyway**.
- **Linux:** `LIQUIDWAVE.AppImage` — `chmod +x LIQUIDWAVE.AppImage` and run it (glibc 2.35 or newer, e.g. Ubuntu 22.04+).
- **Updates:** the app checks this repository and updates itself (Velopack); the `.nupkg` and `releases.*.json` files are for that.
- **Support & privacy:** https://liquidwave.app/support · https://liquidwave.app/privacy
